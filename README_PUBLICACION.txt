SPELLING BEE TRAINER 4.0 - PUBLICACION INICIAL

1. Descarga el ZIP del sitio y descomprímelo.
2. En tu repositorio de GitHub, conserva la rama main y la carpeta raiz de Pages.
3. Sube index.html y las carpetas data/ y assets/ con sus rutas completas.
4. Confirma los cambios y espera el despliegue de GitHub Pages.
5. Abre el sitio y verifica que la Semana 1 cargue y los juegos funcionen.

CADA SEMANA
1. Abre Spelling_Bee_Studio_v4_Local.html en un navegador compatible.
2. Importa el archivo data/manifest.json ACTUAL de tu repositorio.
3. Crea una semana con ID unico (week-02, week-03...).
4. Completa las palabras, oraciones, traducciones y carga una imagen por palabra.
5. Descarga el ZIP y extrae su contenido.
6. Sube los archivos data/manifest.json, data/week-XX.json y assets/words/*
   a sus rutas correspondientes en GitHub. No subas solo el ZIP.
7. Verifica la semana nueva en el sitio publico.

SEGURIDAD
- El editor no publica ni accede a tu cuenta de GitHub.
- No introduzcas tokens ni contrasenas en el editor.
- GitHub Pages es publico: las listas e imagenes publicadas seran accesibles.
- Protege tu cuenta GitHub con autenticacion de dos factores.
- Guarda una copia del proyecto editable JSON en tu dispositivo.

LIMITACIONES
- La app usa sintesis de voz del navegador, que puede requerir un toque en iPad.
- No se incluye autenticacion ni sincronizacion de puntuaciones entre dispositivos.
- El editor local necesita soporte de canvas y descargas en el navegador.
